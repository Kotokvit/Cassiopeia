## 🏛 1. АРХИТЕКТУРА И МЕСТО В МУЛЬТИВСЕЛЕННОЙ

Вселенная **«Кассиопея»** является интегральной частью единого пространственно-временного континуума наряду с **«Этерией»**:
1. **Единая проективная геометрия $\mathbb{P}^3$:**
   * Межзвёздная астронавигация базируется на двойном отношении четвёрок точек (Cross-Ratio) и метрике Фубини — Штуди в проективном гильбертовом пространстве, исключая погрешности классических систем и необходимость атомных часов.
2. **Аксиома Вериса и метаболическая механика:**
   $$V = -k \cdot \Delta H$$
   * Прямая связь между семантической энтропией, гравитационным полем ($1.4g$) и расходом биохимической энергии (баланс АТФ).
3. **Квантовый резонанс и Рунический синтаксис:**
   * Управление плотностью материи, фазовые переходы и квантовое туннелирование сквозь Разрыв Глубокого Яра.

## ⚡ 3. ИСПОЛЬЗОВАНИЕ И РАБОТА С ЯДРОМ POLER ENGINE

Для быстрого контекстного поиска, факторизации и расчётов по материалам репозитория используется нативный CLI **`poler-engine`**:

```bash
# Семантический поиск по всему корпусу Кассиопеи:
poler-engine /home/vitalij/Стільниця/Cassiopeia -q "Аксиома Вериса гравитация 1.4g" --format ai-json

# Астрономические расчёты параметров системы Гелиос-Кассиопея:
poler-engine calc "au_to_km = 149597870.7; r = 1.42 * au_to_km"
```
