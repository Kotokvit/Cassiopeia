Реєстр Системних Порушень: «Кривавий Аудит Глибокого Яру»
Кінетична ліквідація «Якорів Знань»: Страта старійшин племені «Відголосків», які володіли усними кодами доступу до технологій Древніх.
Деструкція архетипових вузлів: Навмисне спалення дерев'яних фігурок та артефактів, що служили когнітивними якорями для стабілізації психіки резонаторів.
Порушення порогу 13/18.5: Примусова праця осіб віком 8-10 циклів (Сел, Юна) у зонах з підвищеною гравітаційною ентропією.
Технецієва деривація: Навмисне зниження концентрації технецію Tc-43 у пайках полонених для виклику метаболічного шоку та покірності.
Біомеханічне мародерство: Вирізання надщільних м'язових волокон (1.47 г/см³) у вбитих воїнів для продажу на чорному ринку «запчастин».
Рунічна тахікардія: Використання несправних гліфів-дисонататорів для розваги, що викликало у дітей ЧСС понад 232 уд./хв без бойової потреби.
Саботаж «Вівтаря Сну»: Руйнування низькочастотних резонаторів (7.8 Гц), що підтримували циркадні ритми селища, викликавши колективне безсоння та галюцинації.
Селективна ампутація резонансних вузлів: Видалення нервових закінчень на кінчиках пальців потенційних «Редакторів» для унеможливлення «зчитування ниток».
Експериментальна «Іржавиця»: Навмисне зараження біологічних споруд селища техногенною гниллю для спостереження за швидкістю розпаду.
Інформаційна стерилізація: Знищення сімейних реєстрів «Відголосків», що перетворило вільних людей на «Товар без минулого» (Самоволку).
Гравітаційне знущання: Примусове утримання полонених у підвішених клітках, де через 1.4g виникали незворотні деформації суглобів.
Примусовий «Синхрон»: Зв'язування двох резонаторів протилежних частот до моменту їхнього спільного нейронного вигорання.
** Harvesting «Песен Крові»:** Забір ліквору у талановитих дітей під час емоційного піку для синтезу дешевих стимуляторів.
Руйнація стабілізаторів океану: Саботаж прибережних установок, що призвело до затоплення нижніх житлових печер селища.
Використання дітей як «Живих сканерів»: Засилання 8-річного Села в зони аномалій для перевірки безпечного шляху.
Брендування очей: Випалювання серійних номерів на рогівці за допомогою лазерних гліфів (Стаття 12-Г).
Хімічне придушення емпатії: Введення препаратів на основі ртуті для блокування «першого замку» зсередини, викликаючи каскадні збої особистості.
Тест на «Граничне навантаження»: Залишення полонених без води під прямим випромінюванням Геліоса для заміру витривалості щільних тканин.
Стимулювання канібалізму: Підміна Нутрієнтної Матриці на органіку загиблих одноплемінників для повної моральної дезінтеграції.
Торгівля «Відлунням»: Продаж записів Криків вмираючих резонаторів як сенсорного контенту для еліти Уламка.
Навмисне викликання ПСС-01: Психологічний тиск на дітей з метою спровокувати Синдром Резонансного Відлуння для подальшого вивчення «аномалії».
Використання «Стигійської сталі» для таврування: Нанесення глибоких рубців, які не гояться через технецієву інтерференцію.
Стерилізація репродуктивних функцій: Хімічна кастрація молодих самців для підвищення їхньої «слухняності» як активів класу Δ.
Створення «Химер Пам'яті»: Використання голограм загиблих батьків для маніпуляції Селом під час тортур.
Лотерея «Списання»: Публічне вбивство кожного десятого полоненого для підтримки стаціонарного рівня страху.
Забруднення «Чистої Води»: Скидання відпрацьованих ізотопів технецію в питні джерела селища.
Виривання мов резонаторам: Механічне видалення голосових зв'язок у «співаків», щоб вони не могли «звучати» проти банди.
Примусове роз'єднання «Зграї»: Продаж братів і сестер у різні Октанти для знищення їхньої резонансної зв'язності.
Маніпуляція «Плацентарним Кризом»: Примусове запліднення жінок з подальшим вилученням плоду для «технічних потреб» Картелю.
Повне «Обнулення Контексту»: Примусове змушування Скії «відредагувати» власні спогади про дім під загрозою смерті Села
